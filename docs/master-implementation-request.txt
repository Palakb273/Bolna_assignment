Calls a customer through Bolna, conversationally collects their Indian address in English/Hindi/Hinglish, handles interruptions and corrections, converts the conversation into deterministic structured address state, validates the address using postal data, reads the exact current address back to the customer, obtains confirmation for that exact version, and stores the confirmed address safely.

8. ADDRESS VERSIONING

10. PIN RULES
Canonical PIN:
exactly six ASCII digits

Allow deterministic normalization only for explicitly supported input:
Unicode decimal digits
explicitly allowed spacing

Reject:

arbitrary compatibility characters

Example:

→ normalization proposal → "500032"

Never guess O vs zero.
